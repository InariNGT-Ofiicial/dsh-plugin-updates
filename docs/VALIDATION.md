# 验证口径

离线测试使用合成包与网络响应，验证来源识别、版本比较、下载限制、摘要、锁、安装结果、回退和人工设置。`npm run check` 检查 JavaScript 语法，`scripts/verify-package.mjs` 对照本地来源核对打包文件。

Windows 上的 DSH 0.2.1-rc.2 隔离 profile 已验证正式 tarball 安装、默认设置、四个工具、合成插件自动升级、保留已加载代码直到重新启动，以及新版本在重新启动后加载。GitHub 响应由夹具提供，官方安装器实际执行。已通过 22 项宿主断言。

发布 CI 在 Windows 和 Linux 的 Node.js 24 环境运行语法、离线测试和安装包内容核对。CI 不启动 DSH、不访问真实用户 profile，也不进行真实平台写入。

实际 GitHub Release 下载、公开 URL 安装和本插件自身升级属于独立的发布后检查。其验收记录保留本地，不把用户机器的 profile、路径、账号配置或安装历史上传至仓库。

以上验证不表示所有插件和宿主版本均兼容；业务功能需由相应插件的使用者在重新加载后核对。当前版本只声明已核对的 DSH 版本范围。
